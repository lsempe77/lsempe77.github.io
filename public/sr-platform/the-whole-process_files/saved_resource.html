A systematic review is a loop, not a conveyor belt.

The stages run in order on paper — protocol, search, screen, extract, appraise, synthesise, report — but the real work doubles back constantly, and screening happens twice: once on titles & abstracts, again on full text. Every AI-assisted step is calibrated against human judgement before it's trusted, using one shared loop.

The calibration engine

⟲ one loop, every AI step

The same loop runs at every AI-assisted step, each with its own instrument and gold set: pilot a batch → run the instrument → measure against human truth → tune → re-run → promote at scale.

Worked example — title/abstract screening
1Humans screen a seed batch (200) — the gold set.
2Run the LLM over the same batch, config v1.
3Compare — recall, precision, WSS, disagreements.
4Tune the prompt — exclusion hints, design filter.
5Promote to the full corpus — auto-decide stays gated.

Each run is scored against the seed batch (D12 harness); each prompt edit is a versioned, provenance-stamped config (D13). Exposing the evaluator over HTTP and this object are the new backend pieces.
