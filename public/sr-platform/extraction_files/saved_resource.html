Ten typed field kinds, not one free-text box

a schema, not a spreadsheet with headers
Structured, not stringly-typed
textintegerdecimalenumboolean dateeffect_estimatespan_reflisttable
effect_estimate alone is a bundle — n / mean / SD / events / effect / CI — the exact shape a meta-analysis needs, captured once at extraction rather than reverse-engineered from prose later.
The confirmation gate, everywhere
Every AI-filled field renders with the same dashed amber gate until a human clicks Confirm. There is no code path that lets an unconfirmed value reach a pooled estimate or a report.
Span-anchored, always
A span_ref value is a pointer into the parsed PDF, not a page number typed from memory. Verifying an AI extraction means reading the highlighted sentence, not re-reading the whole paper.
Hierarchical coding, decoupled
Free-form thematic codes apply to a reference or a text span independently of the typed extraction form — useful the day a review needs qualitative synthesis on top of the quantitative fields.

This is a static direction for the extraction screen, not wired code. It reuses the confirmation-gate and provenance vocabulary already set in the Design Language artifact — the new pattern this screen adds to the shared kit is the typed-field row and the span-anchor preview panel.
